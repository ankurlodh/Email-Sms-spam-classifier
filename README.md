# Email-SMS-Spam-Classifier

A Machine Learning project that classifies SMS messages as Spam or Ham using TF-IDF and Multinomial Naive Bayes.

## Technologies Used

- Python
- Pandas
- Scikit-learn
- TF-IDF
- Multinomial Naive Bayes
- Streamlit

## Model

The project uses TF-IDF for text feature extraction and Multinomial Naive Bayes for classification.

## Features

- SMS spam detection
- Text preprocessing
- TF-IDF feature extraction
- Machine Learning classification
- Spam/Ham prediction
